# 项目记录格式

在每集工作目录保存下述信息。允许Markdown、JSON或宿主工程原生格式；字段含义保持清楚，不要求某个固定软件。

## 任务规格

记录素材清单、输入类型、输出画幅与尺寸、帧率、播放速度、表达路线、外观主题、字幕样式、交付位置、当前授权范围。默认9:16；其他值按用户要求或实际素材确定。

## 剪辑与同步

每个保留片段记录源文件／资产、源起止、成片起止、速度和取舍理由。源与成片范围均采用半开区间[start,end)，说明单位是秒还是帧。恒定速度片段满足：源持续时间＝成片持续时间×播放速度；特殊变速按实际时间映射，不能套这个简式。

每个图解段记录以下项目：

| 项目 | 含义 |
|---|---|
| 时间段 | 最终成片起止时间，允许回查源时段 |
| 保留口播 | 驱动该段的实际短语，不是润色后的文案 |
| 观看目标 | 本段需要看懂的对象、关系或差异 |
| 图形结构 | 流程、坐标、网络、对比、真实材料等 |
| 构图 | 真人主画面／图解＋圆窗／真人＋高亮小图 |
| 提示点 | 哪个短语触发哪条线、哪个标注或高亮；注明时间来源 |
| 风格 | 表达路线与外观主题分别记录 |
| 资产与参数 | 可编辑图形、字体、颜色、当前高亮、圆窗裁切 |
| 核验 | 实际查看的帧、试听的时段、结论与限制 |

仅有脚本而没有音频时，提示点采用短语定位，并标注“待音频定时”。预测时长只作规划，不能称为精确同步。

## 可复现资料

交付工程应可定位到原素材，并包含图形的结构与可编辑源、最终字幕、字幕时序、构图信息和取舍记录。云编辑器工程可用真实工程链接加记录；本地工程保留相对资产索引，避免把另一台机器的绝对路径写成必需依赖。

个人默认偏好与每集覆盖分开保存。今天的四象限、赭橙色、300像素圆窗和1.25倍速只属于已验证的案例参数；可迁移的是轴端标注、脸部居中、字幕居中、局部高亮和总结关系的方法。
