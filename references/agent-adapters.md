# 跨Agent执行

核心文件使用通用Agent Skills结构与普通Markdown，不使用某个Agent专有的命令注入、模型等级、绝对素材路径或私有凭证。`agents/openai.yaml`仅是Codex界面附加信息，其他宿主可忽略。

## 先确认实际能力

| 所需能力 | 可用时 | 缺少时 |
|---|---|---|
| 读取媒体与源文件 | 检查真实原片与元信息 | 请求必要输入，先进行脚本拆解 |
| 语音转写 | 转写并抽核原声 | 使用用户给的稿，标明尚未与录音核对 |
| 精确剪辑与时间映射 | 保留源时间、速度与成片时间 | 输出剪辑决策与所需源时间，不能虚构已剪结果 |
| 图形与动画渲染 | 原生图形、SVG／HTML／Canvas或已有渲染器 | 给出可渲染图形规格；静态方案不能冒充动画 |
| 合成、字幕与导出 | 使用实际工具创建工程并导出 | 交付镜头表、图形、字幕和工程记录，列明缺失环节 |
| 查看和试听 | 看实际合成与导出结果，听剪口 | 报告已完成的核验范围，不虚称全片试听 |

按能力映射工具，不要求同名MCP。不因为接入了工具就改变用户选定的剪辑平台。

## 原生编辑器路线

适用于已有ChatCut或其他可编辑时间线的环境。保持主口播、图形、浮窗、字幕独立可修改；图形尽量保留可编辑文本、颜色和高亮参数。先读取当前宿主工具说明与对应技能，避免把一个平台的字段传给另一个。

ChatCut特有事项仅在使用ChatCut时生效：

- 先读取当前会话提供的基础、口播、动态图形、导出与验证指南；安装目录或工具名称变化时重新发现。
- 改变播放的说话内容时，使用其脚本／转写剪辑流程；布局、静音圆窗和图形放置才用普通时间线项目编辑。
- 字幕使用专门字幕接口，不创建普通“字幕视频轨”。读最终字幕卡核对外置SRT，而不是直接输出原始转写。
- 自写动态图形按宿主要求以完整代码提交，参数来自资产实际属性；先看合成画面再批量复用。
- 素材时间、源播放速度、主轨与圆窗一致。圆窗静音，不重复合成人声。
- 原生裁切可能按未裁的源画面尺寸存储，边框与阴影按最终可见框核对，不能直接照搬上一集裁切参数。
- 导出方式受当前工具限制时说明影响，选择任务授权内可行的实现；不能假定某种音频倍速一定支持。

## 本地制作路线

适用于具备文件读取、时间线／媒体工具和图形渲染能力的Agent。可按实际环境使用现有编辑器、FFmpeg以及SVG／HTML／Canvas渲染；无需全部安装。

保留原声剪辑决策、源到成片映射、图形源文件、字体来源与字幕。透明图形可单独渲染后合成；需要圆窗时保留原始说话画面的真实帧。把输出画幅、帧率、裁切和时间提示点放入项目记录，不能只留下扁平MP4。

若选用花叔引擎，按当时版本读取相关文档、核对许可并试渲；其风格样例用于理解方法，不复制其中的人物、私有音色或具体内容。不依赖固定临时目录。

## 仅能读取文档的Agent

把本技能和需要的参考文档作为任务资料使用。可以完成内容取舍建议、镜头表、图形规格、风格建议和排版方案。没有剪辑、渲染或文件输出能力时明确这一层级；完整执行仍需要相应工具。

## 安装适配的边界

Codex、Claude Code与WorkBuddy的公开文档均提供技能结构；文档格式兼容不等于每台机器都具备剪辑能力。豆包工作模式及其他宿主的自定义技能导入方式，应以实际产品版本和官方说明为准；未经实测不能写“所有平台一键安装通过”。

安装与调用说明见技能目录中的`README.md`。不要把本技能自动安装到用户未指定的其他产品，也不要自行发布到技能市场。
